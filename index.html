RS Horizons Disclaimer

RS Horizons is a massive community map combo that combines numerous third-party map modifications into a single experience.

While every effort is made to ensure stability and compatibility, it is impossible to test every road, city, company, job, and map connection across the entire project.

By installing and using RS Horizons, you acknowledge that:

  • Bugs, missing roads, invisible walls, map gaps, crashes, and other issues may occur.
  • Future ETS2 updates or map updates may temporarily break compatibility.
  • Mod conflicts can cause crashes, missing assets, or profile corruption.
  • No guarantee can be made that every route or area is fully tested.

Recommended Installation Practices

  • Always create a NEW, dedicated profile for RS Horizons.
  • Do NOT use your main profile.
  • Do NOT use profiles containing unrelated mods.
  • Follow the official load order exactly.
  • Keep regular backups of your profile and save games.
  • Remove incompatible mods before reporting issues.
  • Join the Discord server for support before assuming an issue is caused by RS Horizons.

The RS Horizons team and contributors cannot be held responsible for damaged saves, corrupted profiles, lost progress, crashes, or issues resulting from incorrect installation, conflicting modifications, or future game updates.

If you encounter a problem, please report it through the Discord server with as much information as possible, including ETS2 version, load order, location, screenshots, and game.log details.

Thank you for helping us improve RS Horizons and making the project better for everyone.
